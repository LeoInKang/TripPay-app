# Play 데이터 보안 답변안

Play Console → 정책 및 프로그램 → 앱 콘텐츠 → **데이터 보안**에서 아래대로 답한다.
**제출은 Leo가 직접** (양식 제출은 대신 하지 않는다).

현재 제출된 답(2026-07-19)은 **"앱에서 데이터를 수집 또는 공유하지 않습니다"** 인데,
링크 공유가 실제로 데이터를 서버로 보내므로 사실과 다르다. 프로덕션 신청 전에 고쳐야 한다.

---

## 1단계 · 데이터 수집 및 보안

| 질문 | 답 | 근거 |
|---|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | 공유 실행 시 여행 데이터가 서버로 전송됨 |
| 전송 중인 모든 사용자 데이터가 암호화되나요? | **예** | HTTPS + 본문 자체가 AES-256-GCM으로 암호화됨 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 앱 내 "공유 취소"로 즉시 삭제. 7일 후 자동 삭제 |

## 2단계 · 데이터 유형

공유 시 전송되는 항목만 선택한다. 앱을 그냥 쓰는 동안에는 아무것도 전송되지 않는다.

| 분류 | 유형 | 선택 |
|---|---|---|
| 개인 정보 | **이름** | ✅ 참석자 이름이 포함됨 |
| 금융 정보 | **기타 금융 정보** | ✅ 회비·지출 금액과 정산 결과 |
| 앱 활동 / 기기 ID / 위치 / 연락처 등 | — | ❌ 해당 없음 |

※ 이메일·전화번호·주소·결제수단·정확한 위치는 앱이 아예 다루지 않는다.

## 3단계 · 데이터 취급 및 처리 (위 두 유형 각각에 동일하게)

| 질문 | 답 |
|---|---|
| 수집됨 / 공유됨 | **둘 다 해당** (기기 밖으로 나가고, 링크를 받은 사람이 열람) |
| 처리 목적 | **앱 기능** (정산 결과를 참석자에게 전달) |
| 필수 / 선택 | **선택** — 공유 버튼을 누를 때만 발생 |
| 임시 처리인가 | **아니요** — 서버에 최대 7일 보관 |

## 심사 질문에 대비한 설명

혹시 검토자가 "왜 이름·금융정보를 공유하는가"를 물으면 이렇게 답하면 된다.

> 사용자가 정산 결과를 동행자에게 전달하기 위해 직접 공유를 실행할 때만 전송됩니다.
> 전송 전에 기기에서 AES-256-GCM으로 암호화되며, 복호화 키는 링크의 프래그먼트(`#` 뒤)에만
> 담겨 서버로 전송되지 않습니다. 따라서 개발자와 인프라 제공자 모두 저장된 내용을 열람할 수
> 없습니다. 데이터는 7일 후 자동 삭제되고, 사용자는 앱에서 즉시 삭제할 수 있습니다.
